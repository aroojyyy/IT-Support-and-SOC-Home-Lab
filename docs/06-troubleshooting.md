# Troubleshooting

During my lab implementation, I worked with VirtualBox networking, Windows Server configuration, Active Directory, and Splunk log forwarding.

## VirtualBox and Networking
- I checked the virtual machine's network adapter settings.
- reviewed Windows IP and DNS configurations.
- investigated network connectivity issues.

## Windows Server and Active Directory
- I reviewed Windows services.
- checked network and domain configurations.
- used Event Viewer to inspect system and security events.

## Splunk and Log Forwarding
- I checked Splunk Enterprise service status
- checked Splunk Universal Forwarder service status.
- reviewed log forwarding configuration.
- Searched for incoming Windows events in Splunk.
