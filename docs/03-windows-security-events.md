# Windows Security Events

I Used Windows Event Viewer to explore system and security activities and understand how Windows records user and system events.

## Failed Logon Event – Event ID 4625
Performed controlled failed login attempts to generate Windows Security Event ID `4625` and reviewed the event through:

**Event Viewer → Windows Logs → Security**

I examined the event details to understand how Windows records failed authentication activity and how these events can be used for security monitoring.
